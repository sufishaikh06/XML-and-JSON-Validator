XML and JSON Validator

A pushdown automaton checks nesting with a stack. Each opening tag or bracket is pushed; each closing one must match the top, then it is popped. An empty stack at the end means the input is accepted.

Upload a .xml or .json file (or drag it onto the box). It is validated at once and the type is detected automatically. Shortcut for typed text: Ctrl + Enter. Checks nesting only: XML tag order, and JSON { } and [ ] order. Commas, colons and values are not checked. Characters inside JSON strings are skipped.

ReadyPaste a document and press Validate.
